# Qeshev

יישומון אנדרואיד להאזנה, בלי תמונות, בלי וידאו ובלי דפדפן פנימי.

**לשוניות:** בית · פודקאסטים · סרטונים (שמע בלבד) · מוזיקה · ספרייה

- **בית:** המשך האזנה, המלצות לפי מה ששמעת לאחרונה, פרקים חדשים מהפודקאסטים שאתה עוקב אחריהם.
- **פודקאסטים:** חיפוש במאגר הפתוח של אפל, והשמעה ישירות מה-RSS.
- **סרטונים ומוזיקה:** חיפוש ביוטיוב וביוטיוב מיוזיק (שירים, אלבומים, פלייליסטים) דרך NewPipeExtractor. רק זרם השמע נטען.
- **המשך אוטומטי:** כשהתור נגמר, מתווסף משהו דומה. אפשר לכבות את זה.
- **ספרייה:** אהובים, תיקיות, היסטוריה, קבצים שמורים (Music/Qeshev ו-Podcasts/Qeshev).
- **נגן:** תור, מהירות, דילוג של 10 ו-30 שניות, וזכירה של המקום שבו עצרת.
- **מראה:** מצב בהיר/כהה (אוטומטי או ידני), וגודל תצוגה שמותאם לבד למסך, עם אפשרות לשנות ידנית.

בהתראה ובמסך הנעילה אין תמונות. במקום עטיפות מוצג ריבוע צבעוני עם האות הראשונה.

הבנייה רצה אוטומטית ב-GitHub Actions בכל דחיפה לענף `qeshev`, וה-APK מתפרסם ב-Releases בשם `qeshev-<מספר>`.

אייקוני הממשק: Material Symbols של Google (רישיון Apache 2.0).
