# קשב

יישומון אנדרואיד להאזנה לפודקאסטים, בלי תמונות, בלי וידאו ובלי דפדפן פנימי.

- חיפוש פודקאסטים במאגר הפתוח של אפל, והאזנה ישירות מפיד ה-RSS שלהם.
- חיפוש ביוטיוב עם שמע בלבד (דרך NewPipeExtractor), עם מצב מוגבל של יוטיוב.
- נגן ברקע עם שליטה מההתראה. בהתראה ובמסך הנעילה אין תמונות.
- שמירת פרקים כקבצי שמע רגילים בתיקייה `Podcasts/Keshev`.
- ספרייה של פודקאסטים, וזכירה של המקום שבו עצרת.

הבנייה רצה אוטומטית ב-GitHub Actions בכל דחיפה לענף `keshev`, וה-APK מתפרסם ב-Releases בשם `keshev-<מספר>`.
