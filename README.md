# JUBAL (formerly Qeshev)

*PURE AUDIO EXPERIENCE*

יישומון אנדרואיד להאזנה, בלי תמונות, בלי וידאו ובלי דפדפן פנימי.

**לשוניות:** בית · חיפוש · ספרייה · הגדרות

- **בית:** קיצורים למה ששמעת לאחרונה, המשך האזנה להסכתים ולמוזיקה, האמנים האהובים שלך, אלבומים מומלצים, שירים בשבילך, פרקים חדשים והסכתים שאולי תאהב.
- **דף אמן:** פופולריים לפי כמות השמעות, סינגלים חדשים, אלבומים, "נגן הכול" (כל האלבומים לפי הסדר), ערבוב ומעקב.
- **דף פודקאסטר:** כל ההסכתים שלו והסכתים דומים לפי הקטגוריות של Apple Podcasts.
- **חיפוש:** תוצאות מקובצות (שירים, אמנים, אלבומים, פלייליסטים, הסכתים, פרקים, סרטונים), חיפושים אחרונים וקטגוריות.
- **ספרייה:** אהבתי, פלייליסטים, אלבומים, אמנים, הסכתים, הורדות והיסטוריה.
- **המלצות:** רק ממה שבחרת לשמוע בעצמך, ברוח יוטיוב וספוטיפיי. מה שמתנגן לבד מתור, אלבום או השמעה אוטומטית לא נחשב, ודילוג בתוך 30 שניות נחשב נגד.
- **קישורים:** קישורים מיוטיוב, יוטיוב מיוזיק, ספוטיפיי ו-Apple Podcasts נפתחים ב-JUBAL (דרך "שיתוף" או כקישור), בשמע בלבד. ספוטיפיי מותאם לפי שם.
- **פרטים ושיתוף:** תיאור מלא לכל שיר, סרטון ופרק, ושיתוף או העתקה של הקישור המקורי.
- **מראה:** מצב בהיר/כהה (אוטומטי או ידני), וגודל תצוגה אוטומטי עם אפשרות לשנות ידנית.

הבנייה רצה אוטומטית ב-GitHub Actions בכל דחיפה לענף `qeshev`, וה-APK מתפרסם ב-Releases בשם `jubal-app-<מספר>`.
היישומון שומר על אותו מזהה ואותה חתימה כמו Qeshev, כך שהוא מותקן מעליו ושומר את הנתונים.

אייקוני הממשק: Material Symbols של Google (רישיון Apache 2.0).
